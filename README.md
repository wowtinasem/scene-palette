# Scene Palette

미술과 음악 용어를 몰라도 이야기에서 그림 스타일, 사운드 팔레트와 20장 스토리보드를 설계하는 콘텐츠 미술감독 웹앱입니다.

## 주요 기능

- 같은 장면을 낭만주의 유화, 수채화 동화책, 고전 판화로 비교
- 선택한 스타일의 비주얼 바이블 제공
- Suno 및 Google Flow Music용 음악 제작문 생성
- 《오만과 편견》 예시를 이용한 20장 스토리보드
- 제작안 복사 및 JSON 내려받기

## 실행

별도의 설치나 빌드 없이 저장소의 `index.html`을 열면 됩니다. Vercel에서는 프레임워크를 **Other**로 두고 저장소 루트를 그대로 배포할 수 있습니다.

## 기술 범위

- 외부 API, 백엔드 서버, 데이터베이스가 필요하지 않습니다.
- API 키와 환경변수가 필요하지 않습니다.
- 모든 선택과 결과 생성은 브라우저 안에서 실행됩니다.
- 인터넷 연결은 미술관 참고 링크를 열거나 사이트를 배포할 때만 필요합니다.
